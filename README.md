# ISM Mobile

A mobile app for IIT (ISM) Dhanbad students, campus life in your pocket.

🔗 **Live demo:** https://dhanbad.vercel.app/

## What it does

Built for IIT ISM Dhanbad's student community, a single mobile-friendly app for the things students actually need day to day on campus, instead of scattered WhatsApp groups, PDFs, and department websites.

## Status

Built and deployed via Vercel; the live app is the source of truth. This repository tracks the project on GitHub as a reference point - see the demo link above for the actual product.
